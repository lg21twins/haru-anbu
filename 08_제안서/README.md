## 3. 지금 말하는 방식 — 여기만은 틀리면 안 된다

여러 회차의 검증을 거쳐 확정된 표현이다. **바꾸지 않는다.**

| 항목 | 이렇게 말한다 |
|---|---|
| 요청 | **2단계다.** 지금 = 현장 인터뷰 2시간 · 자문. 나중 = 8주 파일럿(개발 2~4개월 후) |
| 시장 규모 | 문서엔 **6,361개소**(2025.12 통계연보), 구두엔 **6,370개소**(2026 1분기 경영공시) |
| 인력 전망 | **1.5~1.9명 → 3.0~3.7명**(KDI 2026.4). *"최대 3.7"로 쓰지 않는다* |
| 차별점 | **"장기요양 입소시설을 대상으로는"** 본인 앱을 확인 못 했다. 한정어 필수 |
| 차별점(2) | **확정 문장은 이것 하나다** — 「**요양보호사가 남긴 돌봄 기록을 어르신 본인을 포함한 네 역할에게 전달하는 구성**」. "네 역할 연결"도 "본인 앱"도 **단독으로는 차별점이 아니다** — Icon은 본인 앱이 있고(돌봄 기록 없음), How's Mom·케어포는 돌봄 기록을 전달한다(본인 앱 없음). 2026-08-07 국내외 전수 대조 |

| 가격 | 아직 안 정했다. **다만 시장이 월 3만 원대인 건 안다** |

## 4. PDF를 다시 만들려면

```bash
cd '08_제안서/시각화'
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-sandbox --virtual-time-budget=9000 \
  --no-pdf-header-footer --print-to-pdf="../PDF/하루안부_제안서.pdf" \
  "file://$PWD/제안서_시각화.html"
```

HTML ↔ PDF 대응은 이름이 같다(`제안서_시각화.html` → `하루안부_제안서.pdf`).
시각화 HTML은 `../../07_디자인/tokens/tokens.css`와 `../assets/`를 참조한다 — **폴더를 옮기면 이 두 경로를 고쳐야 한다.**

### 쪽 높이가 고정된 문서는 뽑기 전에 재 본다

`짧은_제안서` · `자료지도` · `KHF_인쇄물` · `KHF_팀브리핑`은 `.page{height:297mm}`로 쪽을 박아 뒀다.
**내용을 늘리면 조용히 잘린다** — PDF 쪽수는 그대로라 눈치채기 어렵다.

임시 사본에서 `height:auto`로 풀고 자연 높이를 `document.title`에 찍어 `--dump-dom`으로 읽는다.
**A4 = 1123px**(96dpi). 넘으면 그 쪽만 조판을 조인다 — 다른 쪽까지 건드리지 않는다.

```
.page{height:auto !important; min-height:0 !important; overflow:visible !important}
.foot,.cover-foot{position:static !important}
```

이미지가 있으면 `--virtual-time-budget`을 넉넉히(15000) 준다. 안 그러면 로드 전에 재서 값이 작게 나온다.
