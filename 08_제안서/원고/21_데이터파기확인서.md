# 데이터 파기 확인서 — 근거와 서식

> **왜 이 문서가 필요한가.** `PDF/하루안부_의향확인서.pdf`에 우리는 이렇게 써서 돌린다 —
> *"종료 후 데이터는 파기 또는 익명화하고 **파기 확인서**를 드립니다."*
> **약속한 서식이 존재하지 않으면 그 약속은 문구다.** 이 문서가 그 서식이다.

---

## 1. 이 서식이 서 있는 법 조항

| 조항 | 내용 | 우리에게 적용되는 지점 |
|---|---|---|
| **개인정보 보호법 제21조 제1항** | 보유기간 경과·처리목적 달성 등으로 개인정보가 불필요하게 되면 **지체 없이 파기** | 파일럿 종료 = 처리목적 달성 → **파기 의무 발생** |
| **개인정보 보호법 제21조 제3항** | 파기하지 않고 보존하는 경우 **다른 개인정보와 분리하여 저장·관리** | 연구 목적 보존분이 생기면 분리 보관 |
| **시행령 제16조 제1항** | 전자적 파일 → **복원 불가능한 방법으로 영구 삭제** / 종이 → **파쇄 또는 소각** | 우리는 둘 다 발생한다 (DB + 현장 메모) |
| **개인정보의 안전성 확보조치 기준 제13조 제1항** | 파기 방법의 세부 기준 | 삭제 방식 기재 근거 |
| **개인정보 보호법 제58조의2** | 시간·비용·기술을 합리적으로 고려해도 **더는 특정 개인을 알아볼 수 없는 정보**에는 법을 적용하지 않음 | **익명화 경로의 근거.** 다만 "가명처리"와 혼동하면 안 된다 ↓ |

### 여기서 틀리기 쉬운 것 — 익명 ≠ 가명

| | 익명정보 (법 제58조의2) | 가명정보 (법 제2조 제1호의2·제28조의2 이하) |
|---|---|---|
| 복원 | **불가능** | 추가 정보를 쓰면 복원 가능 |
| 법 적용 | **개인정보보호법 적용 제외** | **여전히 개인정보.** 별도 안전조치·결합 제한 적용 |
| 우리 표현 | "파기 또는 **익명화**" | — |

> **의향확인서에 쓴 "익명화"는 익명정보(제58조의2)를 뜻한다.**
> 가명처리로 남겨두고 "익명화했다"고 말하면 **그건 사실과 다르고, 법적으로도 다른 상태다.**
> 실제로 익명화가 어려우면 **그냥 파기한다.** 애매한 상태로 남기지 않는다.

---

## 2. 우리가 실제로 지킬 수 있는 것만 적는다

파일럿 시점의 우리 상태를 전제로 한다.

| 상황 | 서식에 적을 수 있나 |
|---|---|
| DB 레코드 영구 삭제 | **적을 수 있다** — 개발할 때 삭제 기능을 넣으면 된다 |
| 백업본 삭제 | **적을 수 있다** — 다만 백업 주기·보존일수를 알아야 한다 |
| 클라우드 스냅샷 | **오늘은 못 적는다** — 인프라를 안 정했다. 정한 뒤 채운다 |
| 현장 메모지·인쇄물 파쇄 | **적을 수 있다** |
| 팀원 개인기기 사본 | **적을 수 있다** — 애초에 만들지 않는 것이 원칙 |
| 제3자 제공분 회수 | **해당 없음** — 우리는 제3자에게 제공하지 않는다 |

> **인프라를 정하지 않은 채 "모든 백업에서 삭제했음"에 서명하면 그건 허위 확인이다.**
> 서식의 해당 칸은 **공란으로 두지 말고 "해당 없음"·"미사용"으로 명시**한다.

## 4. 언제 어떻게 쓰나

| 시점 | 하는 일 |
|---|---|
| 파일럿 **시작 전** | 이 서식을 **미리 보여준다.** "끝나면 이걸 드립니다"가 아니라 "이게 그 서식입니다" |
| 파일럿 종료 **7일 이내** | 파기 실시 → 서식 작성 → **기관 확인 서명** 받아 1부씩 보관 |
| 이후 | 기관 보관본이 곧 **우리의 다음 레퍼런스**가 된다 |

> **시작 전에 보여주는 것이 핵심이다.** 시설이 파일럿을 망설이는 진짜 이유는 기능이 아니라
> "학생들이 어르신 정보를 가져가서 어떻게 되는가"다. **끝을 먼저 보여주면 시작을 허락한다.**

---

## 5. 아직 못 채우는 칸 — 정직하게 남겨둔다

| 칸 | 채우려면 필요한 것 | 언제 |
|---|---|---|
| 백업 보존주기 | 인프라(호스팅·DB) 결정 | 개발 착수 시 |
| 클라우드 스냅샷 | 동일 | 동일 |
| 파기 책임자 성명 | 팀 내 역할 확정 | **지금 정할 수 있다** |
| 촬영물 항목 | 촬영 동의서 별건 필요 | 촬영 계획이 생기면 |

> **촬영 동의서는 이 서식으로 대체되지 않는다.** 초상권은 개인정보 파기와 별개 문제다.
> 파일럿에서 사진·영상을 찍을 계획이 생기면 **그때 별도 서식을 만든다.** 지금은 만들지 않는다.
