### A6이 중요한 이유 — 선정작 6건이 전부 하드웨어다

2026년 선정 기관과 도입 기술:

| 기관 | 도입한 것 |
|---|---|
| 강북하루정요양원 · 밝은햇살요양원 | 전동식 자세 변환 침대 |
| 구립용산노인전문요양원 | 비접촉 레이더 모니터링 |
| 서울시니어타운 · 여민복지협동조합 | 전동 리프트, 웨어러블 로봇 |
| 시립송파노인전문요양원 | 스마트 배변 센서 |

**여섯 건 모두 기기(하드웨어)다. 소통 소프트웨어는 한 건도 없다.**
사업 목적이 "돌봄 종사자의 업무 부담을 덜고 서비스의 질을 높이기 위해"인데,
부담 경감을 기기로만 접근하고 있다는 뜻이다.

이것이 하루안부의 진입점이다.
- 규모가 700만원 수준이라 **학생 팀이 감당 가능한 유일한 공공 창구**다
- 신청 주체가 시설이므로 **파일럿 시설을 먼저 잡으면 그대로 이어진다** — Phase 1과 목표가 같다
- 경쟁이 하드웨어에 쏠려 있어 **소프트웨어 카테고리가 비어 있다**
- 서울시 사업이므로 **서울 소재 시설**을 우선 섭외한다

> 지원 전 확인: 신청 자격이 시설 단독인지 기술 파트너 동반이 가능한지, 차기 회차 공모 시기.
> 서울시복지재단 공고를 직접 확인해야 한다.

**핵심 인식** — A1·A2는 우리가 직접 못 넣는다. **지자체를 먼저 잡아야 문이 열린다.**
따라서 제안서의 1차 수신자는 부처가 아니라 지자체·시설이다.

## I. 주의사항

1. **모든 일정은 재확인.** 이 표의 날짜는 2026-08-02 조사 시점 기준이며, 공고는 매년 바뀐다. 지원 직전 공식 사이트에서 확인한다.
2. **중복 출품 규정 확인.** 어워드마다 기출품·기수상작 허용 여부가 다르다. 국내 전람회 계열은 통상 제한이 있고, IDA·MUSE·A'는 관대하다.
3. **케어포 재평가 필요.** 국내 주요 사업자이면서 **가족앱을 이미 보유**한다는 점이 기존 경쟁 분석에서 빠져 있었다. 도입 기관 수는 공식 표기가 없어 **수치 없이 서술**한다(2026-08-07 재확인). **차별화 문장을 쓰기 전에 반드시 실제 앱을 확인**한다.
4. **산업 접촉 시 과장 금지.** "동작하는 서비스"가 아니라 "설계 완성 + 파일럿 제안"으로 정확히 말한다. 실사에서 드러나면 신뢰가 끝난다.
5. **공모전은 목적이 아니다.** 수상은 신뢰 보강 수단이고, 진짜 목표는 파일럿 → 레퍼런스 → 공공사업 편입이다.
