## 1. 프로젝트 개요

- **서비스명**: 하루안부 (하루(日) + 안부(安否) = 매일 안부를 묻다)
- **슬로건**: "오늘 하루도, 안녕하셨습니다"
- **한 줄 컨셉**: "요양원판 토스 + ChatGPT"
- **분류**: AI 케어 커뮤니케이션 플랫폼
- **팀**: 3인 (기획, 개발, 디자인)

### 핵심 문제
- 보호자: 요양원에 가족을 맡기고 오늘 상태를 실시간으로 알 수 없음
- 의료진: 보호자 전화 응대에 하루 2시간 소비
- 환자: 가족과 디지털로 연결될 수단 없음

### 차별화 3가지
1. **유일한 3자 실시간 소통**: 보호자 ↔ 의료진 ↔ 환자 (경쟁사는 최대 2자)
2. **AI 매일 자동 리포트**: Claude API 기반 (국내 유사 서비스 없음)
3. **5개 모드 AI 케어가이드**: 제도안내 / 건강정보 / 감정지원 / 요양원찾기 / 비용계산

## 2. 강점 분석

### 기획 완성도
- **블루오션 포지셔닝**: 국내 6개 경쟁사 모두 입소 전 매칭 또는 시설 운영 집중. 입소 후 3자 실시간 소통 = 완전한 공백 시장
- **3역할 퍼소나 탄탄**: 보호자(김미영), 의료진(박지현/이상훈), 환자(김순자) — 현장 인사이트 v2.1까지 업데이트
- **JTBD + 5 Whys + HMW**: 체계적이고 근거 있는 문제 정의
- **As-Is/To-Be 감정 점수화**: 2점 → 3.5~4점 수치로 개선 표현
- **AI 협업 53개 기록**: 작업 과정의 투명성

### 기술 설계
- **역할별 UI 분기**: 하나의 앱에서 3가지 뷰 — 차별화 포인트
- **Supabase Realtime**: 체크리스트 → 대시보드 3초 반영 (기술적으로 현실적)
- **Claude API 일일 리포트**: 국내 유사 서비스 없음

### 디자인
- **디자인 시스템 완성**: 컬러/타이포/간격/컴포넌트 토큰화
- **노인 접근성 고려**: 18pt+, 48×48px 터치 영역, 고대비
- **목업 v8 + 38장 스크린샷**: 시각적 완성도 높음

## 5. AI 비용 계산

> MVP 기준: 보호자 DAU 1,000명, 환자 500명 가정

### 일일 리포트 (Claude Sonnet 사용)
| 항목 | 수치 |
|------|------|
| 환자 1명 입력 토큰 | ~500 tokens (케어 데이터) |
| 출력 토큰 | ~300 tokens (요약 리포트) |
| 1일 총 토큰 | 500명 × 800 = 400,000 tokens |
| Sonnet 단가 | Input $3/1M, Output $15/1M |
| **1일 비용** | **약 $3.5 (5천원)** |
| **월 비용** | **약 $105 (15만원)** |

### AI 케어가이드 (Claude Haiku 사용 — 비용 절감)
| 항목 | 수치 |
|------|------|
| 보호자 일평균 사용 | 0.5회 × 5턴 대화 |
| 1일 총 토큰 | ~2,000,000 tokens |
| Haiku 단가 | Input $0.80/1M, Output $4/1M |
| **1일 비용** | **약 $4 (6천원)** |
| **월 비용** | **약 $120 (17만원)** |

### 총 정리
| 항목 | 월 비용 |
|------|--------|
| 일일 리포트 (Sonnet) | ~15만원 |
| 케어가이드 (Haiku) | ~17만원 |
| **MVP 총합** | **~32만원/월** |

### 시설 단위 마진 계산
- 100명 환자 요양원 1개 → AI 비용 약 **3만원/월**
- 시설 구독료 99,000원 → **마진 70% 이상**
- 공모전 발표 포인트: "AI 비용은 구독료 대비 30% 수준, 지속 가능한 구조"

## 6. 환자 화면 판단

**현재 3개 (홈 / 가족소식 / 도움요청) — 이미 적절함.**

이유:
- 환자(78세, 치매 초기)에게 많은 기능 = 혼란
- 환자는 "서비스 사용자"가 아니라 "케어의 대상"
- UX 목표: "가족과 연결된 느낌" 하나

### 권장 환자 화면 3개 설계
| 화면 | 핵심 기능 | 설계 포인트 |
|------|----------|-----------|
| **홈** | 오늘 날짜, 날씨, 식단, 오늘 일정 1개 | 텍스트 최소화, 큰 이미지 |
| **가족소식** | 가족이 보낸 사진/한마디 | 사진 중심, 읽기 전용 |
| **도움요청** | 버튼 1개 (도움이 필요해요) | 화면 가득한 버튼 1개 |

→ 균형은 "화면 수"가 아니라 "중요도"로 맞추는 것. 현재 방향 유지.

## 7. 수익 모델 권장안

### 현재 문제
과금 주체가 3개 (보호자/시설/모드별) → 복잡

### MVP 단순화 (2가지)
| 대상 | 구조 | 금액 |
|------|------|------|
| **시설 B2B** | 환자 수 기반 월정액 | 50명 이하 9.9만 / 51~100명 19.9만 / 100명+ 29.9만 |

AI 케어가이드 프리미엄 모드는 검증 후 추가. 공모전에서는 언급만.

## 8. 추가 아이디어

### 보호자 안심 지수
보호자 홈 화면 상단 카드로 구현.

**작동 방식:**
```
이번 주 체크리스트 데이터 (식사율, 투약율, 활동참여, 특이사항)
          ↓
    Claude API 에 전송
          ↓
  0~100점 + 한줄 코멘트 반환
          ↓
  홈 화면 카드에 표시
```

**UI 예시:**
```
┌─────────────────────────────┐
│  이번 주 안심 지수           │
│                             │
│         87점                │
│                             │
│  식사량이 평소보다 좋아졌어요 │
│  투약은 모두 정상 진행 중이에요│
└─────────────────────────────┘
```

**Claude API 프롬프트 구조:**
> "다음 이번 주 케어 데이터를 바탕으로 보호자가 안심할 수 있는 수준을 0~100점으로 평가하고, 따뜻한 한 문장 코멘트를 작성해줘. [데이터]"

### 의료진 업무 시간 절감 계산기
발표 슬라이드 (`05_발표/ppt_v3.html`) 안에 JS로 구현.

**슬라이드 예시:**
```
요양원 규모를 선택해주세요
[ 소형 ~30명 ]  [ 중형 ~100명 ]  [ 대형 100명+ ]

📞 현재: 하루 전화 응대 22통
✅ 도입 후: 예상 11통 감소
⏱ 절감 시간: 월 22시간
💰 비용 환산: 월 44만원 절감

구독료 9.9만원 → ROI 4.4배
```

버튼 클릭 → 숫자 바뀌는 JS 15줄. 발표 때 심사위원 앞에서 직접 클릭하면 임팩트 강함.

## 10. 공모전에 B2B/금액 넣는 방법

**결론: 넣되, 슬라이드 뒤쪽에 배치**

```
문제 → 솔루션 → 사용자 → 기능 → 기술 → [비즈니스 모델]  ← 여기
```

- 앞에 배치 → "돈 얘기부터 하는 팀" 인상
- 뒤에 배치 → "지속 가능한 모델까지 생각한 팀" 인상

**핵심 메시지:**
> "보호자 무료 → 빠른 확산 → 구독료 9.9만원 vs 절감 비용 44만원 → ROI 4.4배"

금액 자체보다 **"왜 시설이 돈을 낼 수밖에 없는가"** 의 논리가 더 중요.
