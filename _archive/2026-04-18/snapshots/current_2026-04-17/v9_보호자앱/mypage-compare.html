마이 페이지 — Before / After

v9 보호자앱 · 마이 페이지 사용성 개선
BEFORE 현재 (g05-mypage.html)
프로필 카드 · 퀵 액션 · 케어 대상 카드가 분리되어 있고, 호실/간호사/경과일 정보가 두 번 반복됩니다.
AFTER 개선안 (g05-mypage-v2.html)
케어 대상자를 주인공으로, 보호자는 1줄 스트립으로. 퀵 액션은 케어 카드에 붙이고, 알림엔 바로 실행할 CTA를 배치했습니다.

핵심 변경 — 구조 개선 (기본)

01 · HIERARCHY
주인공 바꾸기
보호자(손예찬) 프로필이 가장 컸던 기존 → 어머님(손정희) 카드를 최상단·최대로. 보호자는 1줄 스트립으로 축소.
02 · DEDUP
중복 정보 제거
호실/간호사/경과일이 프로필 카드 + 케어 카드 두 번 등장했던 문제 → 케어 카드 안에서 1번만. 정보 밀도 -40%.
03 · GROUPING
퀵 액션 소속 명확히
공중에 떠 있던 소통/기록/AI가이드 3버튼 → 케어 대상자 카드 하단에 통합. "어머님에 대해 뭘 할지"의 맥락이 붙음.
04 · CONSISTENCY
카드 스타일 통일
3종 섞여있던 카드 스타일(연한 파란 배경 / 흰 그림자 / 리스트형) → 흰 배경 + subtle shadow + 20px radius 한 종류로.
05 · STAT STRIP
버튼처럼 보이던 타일 → 플랫 스탯
파란 배경 타일이 "클릭 가능한 버튼"으로 오인됐던 문제 → 배경 제거 + 위아래 구분선만으로 영역 표시. 값 위·라벨 아래 배치해 스캔 속도 향상.
06 · TYPOGRAPHY
위계 3단계로 단순화
들쭉날쭉하던 폰트 크기 → 22px 이름 / 15px 본문 / 12px 캡션. 터치 타깃도 최소 56px로 통일해 누르기 편하게.

시니어 디자이너 레이어 — 감정 온도 올리기

07 · WELCOME
"마이" → 인사 기반 헤더
기능적 제목 "마이"를 버리고 "오늘도 반가워요, 손예찬님"으로 교체. 페이지를 여는 순간 정서적 온도를 올림. 내비게이션 라벨은 하단 탭바가 대체.
08 · LIVE TIMELINE
정적 진단 → 오늘의 하루 타임라인
"고혈압·당뇨, 1일 3회 복약" 같은 늘 그런 정보 대신 "09:15 혈압 정상 120/78, 09:00 약 복용, 08:30 식사 80%" 실시간 활동으로 교체. 보호자가 진짜 궁금한 건 "지금 어떠신가"임. 진단은 서브타이틀로 이관.
09 · NURSE STATUS
알림에 '대응 상태' 추가
"낙상 감지 · 2분 전"만 띄우면 보호자는 패닉. → 알림 안에 "김서연 간호사가 현재 확인하러 가고 있어요" 라이브 인디케이터 배치. 즉각적 안심감이 CTA만큼 중요.
10 · COLOR WARMTH
블루 모노톤 탈피
전체가 파란색으로 차갑던 임상적 톤 → 타임라인 도트에 녹색(정상)·앰버(복약)·블루(식사)·회색(예정)을 의도적으로 섞어 웰니스 상태를 색으로 즉시 전달.
디자인 원칙
이 앱의 핵심 임무는 "어머님이 지금 괜찮으신지"를 빠르게 확인하고 필요하면 즉시 반응하는 것. 구조 개선(01–06)으로 정보를 정돈했다면, 감정 레이어(07–10)는 "이 앱이 내 편이다"라는 느낌까지 전달합니다. 시니어 케어 앱에서 가장 쉬운 실수는 정보 정확성에만 집중해 차갑고 사무적으로 만드는 것 — 사용자는 기능이 아니라 안심을 얻으러 오기 때문입니다.
