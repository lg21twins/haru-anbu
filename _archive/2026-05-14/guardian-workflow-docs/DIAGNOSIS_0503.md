## 화면 간 횡단 이슈 (재정리)

이 7개는 단일 화면 진단으로 안 잡히고 화면 간 비교에서 드러남:

1. **이모지 위반** (CLAUDE.md "이모지 절대 금지"): g-ai 👍 (line 306), g03-chat-family 🍊·👍 (line 286, 296). **iconify로 교체 필수**.
2. **탭바 불일치**: g03-chat = 홈/채팅/리포트/청구/마이 (line 241-257). 다른 화면 = 홈/AI가이드/소통/기록/마이. 보호자가 어느 탭에 무엇이 있는지 학습 X 2회.
3. **g02-ai-report ↔ g-guardian-live 데이터 불일치**: 같은 시점인데 투약 1/3 vs 3/3.
4. **g02-ai-report에서 "오늘의 순간" 사진 사라짐**: 흐름 단절. N2 핵심 격차 — 1차 리서치에서 지적된 그대로.
5. **g09-prescription ↔ g10-timeline 정보 비대칭**: 변경 사유가 g10에만 있고 g09에 없음.
6. **g03-sotong ↔ g03-chat 역할 중복**: 메시지 피드 vs 채팅 허브, 어디로 가야 하는지 보호자가 학습 추가 부담.
7. **다중 보호자 모델 부재**: 가족 그룹 채팅엔 3명(박민지·손예린·손민호) 있는데 g05-mypage·g08-billing·g06-alert에는 "박민지 1명"만 전제. 데이터 모델 불일치.
