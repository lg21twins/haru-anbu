## 요약

화면 구성은 전반적으로 좋습니다. 인트로에서 활성 회진으로 이어지는 흐름, 지난 라운드와 지금 기록을 분리한 카드 구조, 위험도 선택 후 액션시트를 띄우는 방식은 의료진 업무 흐름에 맞습니다.

다만 의료진 앱 특성상 데이터 정확성과 진행 상태 관리는 바로 정리하는 것이 좋습니다. 현재 가장 중요한 문제는 환자 변경 시 헤더/지난 기록/진행 상태가 일관되게 갱신되지 않는 점입니다.

## 우선 수정 필요

### 1. 환자 이름/나이 중복 표시

환자 목록에서 최명자로 이동하면 카드 헤더가 다음처럼 표시됩니다.

```text
최명자 82세 · F
78세 · F
10/15
```

원인은 `renderCard()`에서 `#cName`에 나이와 성별까지 넣고 있는데, HTML에는 별도의 `.card-age` 요소가 그대로 남아 있기 때문입니다.

관련 위치:

- `d02-round.html:684`
- `d02-round.html:873`

개선 방향:

- `#cName`에는 이름만 넣기
- `.card-age`에 `${p.age}세 · ${p.sex}`를 별도로 갱신하기

### 2. 환자를 바꿔도 지난 라운드 데이터가 고정됨

최명자, 김순자 등 다른 환자로 이동해도 지난 라운드 영역은 박영자 기준 데이터로 유지됩니다.

예시:

- 혈압 `130/80`
- 체온 `36.7`
- 무릎 통증 메모
- `박지현 간호사 · 11:32 · 음성 입력`

의료진 화면에서는 환자별 바이탈/메모가 잘못 보이는 것이 가장 위험한 문제입니다.

관련 위치:

- `d02-round.html:696` 이후 summary markup
- `d02-round.html:833` 이후 patients 데이터
- `d02-round.html:868` 이후 renderCard

개선 방향:

- `patients` 각 항목에 `lastVitals`, `lastNote`, `lastRoundTime` 등 환자별 데이터를 추가
- `renderCard()`에서 summary 영역도 함께 갱신

### 3. 환자 목록 이동 후 current 상태가 여러 명으로 남음

환자 목록에서 10번 최명자로 이동하면 9번 박영자와 10번 최명자가 동시에 `current` 상태가 됩니다. 이후 저장하고 다음을 누르면 9번과 11번이 동시에 `current`로 남습니다.

관련 위치:

- `d02-round.html:850`
- `d02-round.html:918`
- `d02-round.html:944`

개선 방향:

- `jumpTo(i)`에서 기존 `current`를 `pending` 또는 이전 상태로 정리
- `swipe('next')`, `swipe('skip')`, `swipe('prev')`에서도 새 current 지정 전 기존 current 정리
- 완료/건너뜀 상태는 유지하고, current는 항상 1명만 갖도록 보장

### 4. 활성 회진 첫 화면에서 하단 탭바가 핵심 입력 영역과 겹침

390x844 모바일 기준에서 위험도 버튼 영역이 하단 탭바 뒤에 걸립니다. 스크롤하면 접근 가능하지만, 회진의 핵심 조작 버튼이 첫 화면에서 가려지는 것은 UX상 아쉽습니다.

관련 위치:

- `d02-round.html:27`
- `d02-round.html:486`
- `d02-round.html:665`

개선 방향:

- `.app` 하단 padding을 더 확보
- 또는 활성 회진 입력 카드를 조금 압축
- 하단 고정 탭바가 주요 CTA와 겹치지 않도록 최소 안전 여백 보장

## 추가 개선 제안

### 위험 환자 기본 상태 반영

`risk:'danger'` 환자로 이동해도 AI 위험 신호 선택값은 항상 `정상`으로 초기화됩니다.

개선 방향:

- `risk:'warn'`이면 `주의` 또는 `관찰`을 기본 강조
- `risk:'danger'`이면 `위험` 기본 선택 또는 위험 배지 표시
- 의료진이 최종 확인한다는 전제는 유지하되, 시스템 판단의 맥락을 놓치지 않게 하기

### 액션 선택 후 지속 상태 표시

`촉탁의 보고`, `인수인계 추가`, `30분 후 재측정 알림`은 현재 토스트만 뜹니다.

개선 방향:

- 카드 내부에 후속 조치 완료 배지 표시
- 예: `촉탁의 보고됨`, `SBAR 추가됨`, `30분 후 재측정 예약`
- 저장하고 다음으로 넘어가기 전에 사용자가 선택 결과를 확인할 수 있게 하기

### 환자 목록 필터 강화

현재 환자 목록은 15명 전체 리스트로만 표시됩니다. 실제 업무에서는 위험/주의/미완료 환자를 빠르게 찾아야 합니다.

개선 방향:

- 상단에 `전체`, `미완료`, `주의`, `위험` 필터 추가
- 현재 진행 중 환자는 sticky 또는 더 강한 강조 처리
- 위험 환자는 목록 상단에서 접근 가능하게 옵션 제공

### favicon 404 정리

브라우저 콘솔에 `favicon.ico` 404가 1개 발생합니다. 기능 오류는 아니지만 정리하면 좋습니다.

개선 방향:

- 공통 favicon 링크 추가
- 또는 서버 루트에 `favicon.ico` 배치
