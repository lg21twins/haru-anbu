PROMPT #50 보호자앱 · 결제 차트 2026.04.13

>"표에 들쑥날쑥 그래프 더미데이터 만들어줘."

— AI 1차 작업 —

>"왜 그대로냐?"

틀린 건 우리가 먼저 잡았다.

AI는 1차에 height % 값만 바꿨고 — 화면은 그대로였다. 우리가 한 줄로 잡자 AI가 원인을 자기 진단하고 구조 자체를 다시 짰다. 우리가 잘 다룬 협업은 정답을 받는 게 아니라, 틀린 답을 알아채는 일이다.

AI 1차 시도

height: X% 값만 변경. 화면은 그대로. .trend-chart { align-items: flex-end } 때문에 자식 열에 height가 잡히지 않음.

AI 2차 — 구조 재설계

align-items: stretch + .trend-col { height: 100% } 으로 컨테이너 구조 자체 수정. Y축 90만~120만 기준 % 재계산.
