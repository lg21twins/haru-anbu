## ATOMX 세트 (2026-08-14 입수) — 판형을 실제로 복제한 원본

NASA 세트에서 뽑은 규칙 위에, 구체적인 판형·장치를 가져온 2차 레퍼런스.

### `ATOMX-01_개요리서치판.png` → **보드1 원본**
XR 소셜 플랫폼 "Tenper" / 프로젝트명 ATOMX 의 개요·리서치판.

가져온 장치:
- 초대형 고스트 워드마크(배경에 반투명 프로젝트명)
- 기울인 3D 폰 2대 + 하늘 그라데이션 배경 + 실사 인물 워터마크
- `User Needs → Solution` 2열 대응표 — 니즈 한 줄마다 해법 한 줄이 마주 본다
- Service Diagram 벤 3원 + 좌우 pill/circle 와 연결선
- `92%` 초대형 수치 + 라인차트
- `How / Who / Why / When / Where` 5W 카드 그리드
- `"Beyond reaction, into relation"` 중앙 정렬 히어로 문장 + 아래로 향한 시각적 화살표

### `ATOMX-02_화면갤러리판_하루안부배치WIP.png` → **보드2 원본**
같은 템플릿의 둘째 장인데 **하루안부 화면이 이미 배치된 작업 중 상태**다.
보호자 홈·일일 리포트, 어르신 태블릿, 요양보호사 오늘, 의료진 웹 대시보드, AI 가이드가 들어가 있다.

주의: **헤드라인 카피는 원본 템플릿이 그대로 남아 있다**
("마이페이지에서 나의 칭찬 활동 내역을 모아보세요", "칭찬 구슬", "칭찬 공개 전/후").
우리 판에서는 전부 교체했다.

가져온 장치:
- 지시선 콜아웃 — 화면 옆으로 선을 뽑아 기능을 지목
- 번호 시퀀스 캡션 `01` `02` — 화면에 읽는 순서를 부여
- 상태 칩 `공개 전` / `공개 후` — 같은 화면의 두 상태를 나란히
- 컬러 블롭으로 화면 군집을 묶기
- 코드 에디터 · 웹 대시보드 · 실사 사진을 폰 사이에 섞어 리듬 만들기
- **번호 캡션의 번호 색이 그 군집의 역할색을 따라간다** — 배경 필 없이 타이포 색만으로 군집 표시

## NASA "Pocket Mission Control" 세트 (2026-08-11 입수) — **1차 레퍼런스, 직접 만든 판**

손예찬이 직접 만든 패널이다. Figma `iNt51HokozrSYHr5ElRZqc` / 3507×2480px = A4 가로 300dpi.
**패널 기획의 출발점**이고, `../_레퍼런스리서치_패널기획.md` §1 이 이 두 장을 해부해
"추출한 규칙 12개"를 뽑아냈다. ATOMX 세트보다 먼저 들어온 상위 레퍼런스.

### `NASA_패널A_개념결정시스템판_node1-5.png` (Figma node 1-5)
개념 · 결정 · 시스템판. 읽는 순서가 Z 가 아니라
좌상단 이미지 → 우상단 타이틀 → 좌하단 브리프 → 중앙 근거 → 우측 결정/시스템 → 하단 탭 카드.

- 좌상단 풀블리드 실사(NASA Atlas V) + 그 위 흰 명패 카드 `Featured by NASA's State-of-the-art Report`
- 우상단 초대형 타이틀 `MORE ACCELERATION` + 자간 넓은 마이크로 라벨
- **CORE IDENTITY 원 3개** — 개념을 3축으로 압축, `×` 기호로 곱셈 표현
- `LAUNCH SYSTEM` 미션 브리프 + 스펙표
- 중앙 **코드 에디터 콜라주**(VS Code · GitHub Codespaces) — "진짜 만들었다"는 근거
- `DESIGN APPROACH` **STEP 1 · 2 · 3** 초대형 숫자 + 결정문
- 시그니지 시스템 + **소실점 `A` 작도** — 브랜드 작도는 시각디자인 심사 득점 요소
- 하단 **탭 카드 4장**(GoPro HERO9) — 라벨 + 헤드라인 + 이미지 + 메타

### `NASA_패널B_화면갤러리판_node1-9.png` (Figma node 1-9)
화면 갤러리판. 천문 앱(Today Sky / Sky Live / Nebula).

- 배경 실사 풀블리드 위에 **폰 목업 10대 + 잘라낸 UI 조각**을 느슨한 대각선으로 배치
- 섹션 마커는 `06 SKY LIVE` `07 NEBULA` `08 TODAY SKY` — **번호 + 초광폭 자간 영문 + 2행 설명만**. 상자·선 없음
- 화면 자체가 유일한 채도. 배경·타이포는 무채색
- 좌하단 코드/앨범 카드 — 갤러리판에서도 "구현물"임을 다시 못박음

### 여기서 뽑은 규칙 12개 (`../_레퍼런스리서치_패널기획.md` §1)
판형 A4 가로 300dpi · **중간 크기 글자를 없앤다**(초대형/소/초소 3단) · 마이크로 라벨은 대문자+자간 0.2~0.3em ·
번호를 시각 요소로 · 구분은 헤어라인 또는 여백, 박스 금지 · 컬러는 화면 캡처가 전담 ·
이미지 크기 계급(지배 1 + 종속 다수) · `라벨 ··· 값` 데이터표 · 캡션은 설명이 아니라 주장 ·
근거 노출(코드·법령·수치 출처) · 하단 러너에 메타 고정 · 국문 `keep-all` 2행 이내.

우리 판에 적용된 것: **패널 A 는 부분 차용**(폰 1대를 지배 이미지로 — 표지 없는 2장 구성엔 과함),
**패널 B 는 골격 기각·조각 클로즈업 개념만 차용**(흰 바탕에선 배경이 없어 성립하지 않음).
