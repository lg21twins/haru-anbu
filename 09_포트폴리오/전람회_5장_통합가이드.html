01

출품 규정 — 무엇을 꼭 지켜야 하나

제60회(2025년) 공고문·접수 페이지 1차 출처 기준. 등급/배지는 검증 신뢰도입니다.

가장 중요한 발견 — “16:9 5장”은 KIDP 규정이 아닙니다 검증 3-0

KIDP 1차 온라인 접수가 강제하는 건 ① 최대 5장(대표 1장 필수+보조 4장 선택) ② 각 이미지 3MB 이내(jpg/png/gif) 뿐입니다. 공고문에 “표현방식 및 레이아웃 제한 없음”이 명시돼 있어, 비율·해상도·DPI·텍스트 비중 규정이 전혀 없습니다. → 즉 16:9는 우리 자체 출력 제약일 뿐이라, 패널에 설명 텍스트·배경 합성·번호 시나리오를 자유롭게 넣어도 됩니다.

1차 온라인 제출물 high

  • 이미지 패널 최대 5장 — 대표 이미지 1장 필수, 보조 4장 선택
  • 파일: jpg / png / gif, 각 3MB 이내
  • (선택) 영상 mp4, 50MB · 5분 이내
  • 비율·해상도·텍스트 비중 규정 없음 = 레이아웃 자유

하루안부에 맞는 부문 high

  • ⑥ 서비스·경험 디자인 — “보건의료, 경험디자인(UX·CX)” 명시. 가장 정합성 높음
  • ③ 디지털미디어·콘텐츠 디자인 — 앱·UI·HCI. 4역할 앱 화면 강조 시 적합
  • 총 7개 부문 체계 (제품 / 시각·정보 / 디지털미디어 / 공간·환경 / 패션 / 서비스·경험 / 산업공예)
  • 부문 번호(③/⑥)는 매년 재번호될 수 있음 — 해당연도 공고 확인

심사가 보는 것 high

  • 실제 사용자 리서치 근거는 필수(must) — 예쁜 UI만으론 부족 (UX Design Awards)
  • iF 5기준: Idea · Form · Function · Differentiation · Impact (2025년부터 5번째는 Sustainability)
  • 첫 장 = 키/대표 이미지 — 가장 강한 시각을 1번에
  • 5장만으로 독립적으로 이해 가능해야 (심사위원이 이해 못 하면 투표 불가) mid

표현 원칙 mid

  • 체감 경험(felt experience)을 전면에 — “보호자가 가족 하루를 받아보는 순간”
  • 핵심 UI·인터랙션 클로즈업 + 개요샷 균형 (클로즈업이 지배 X)
  • 내러티브 정설: 문제 → 사용자 → 리서치/맥락 → 솔루션 → 임팩트
  • 정량 지표는 권장(필수 아님) — 있으면 설득력↑

출품 전 반드시 재확인 — 2026 제61회 공고

위 규정은 모두 제60회(2025년, 접수 5.1~6.30) 기준입니다. 2026년 제61회 공고에서 5장·3MB·부문 분류·번호가 동일하게 유지되는지 award.kidp.or.kr 공식 요강 PDF로 한 번 더 대조하세요.

오해 바로잡기

리서치에서 반증(refuted)된 통념들. 이걸 알고 있으면 불필요한 제약에 갇히지 않습니다.

“패널 이미지 위에 글자(설명 텍스트)를 넣으면 안 된다”
→ 그건 iF Design Award 같은 일부 해외 어워드의 규칙입니다. KIDP 전람회는 “표현방식·레이아웃 제한 없음”이라 설명 텍스트·캡션·번호 시나리오를 자유롭게 얹어도 됩니다.
“A1 실물 패널과 별도 PDF 작품설명서도 함께 내야 한다”
→ KIDP 1차는 온라인 이미지 5장(+선택 영상)만 강제됩니다. ‘A1 실물 패널’은 건축·공간 등 별도 부문의 물리 제출 규정으로 우리와 무관. (단, 2차 본심사 추가 제출물 여부는 해당연도 공고로 재확인)
“정량 성과 수치(측정된 결과)가 반드시 있어야 한다”
→ 정량 지표는 권장이지 필수가 아닙니다(검증서 반증됨). 다만 있으면 설득력이 크게 올라가니, 확보 가능한 지표는 2·5번 패널에 넣으세요.
“비율은 무조건 16:9여야 한다”
→ KIDP는 비율 규정이 없습니다. 16:9는 우리 자체 기준일 뿐. 가독성에 더 좋은 비율(예: 3:2, 4:3)이 있으면 바꿔도 무방합니다. 5장·각 3MB만 지키면 됩니다.
