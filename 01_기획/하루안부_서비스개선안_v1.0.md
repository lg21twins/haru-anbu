# 하루안부 서비스 개선안

**v1.0 | 2026.05.09**

이 문서는 `하루안부_통합기획서_v6.0.md`를 대체하지 않는다. 기존 기획의 넓은 비전을 유지하되, 실제 서비스 완성도와 발표 설득력을 높이기 위해 **MVP, 수익 모델, 리스크, 기능 우선순위**를 다시 좁히는 실행 기준 문서다.

---

## 1. 개선 방향 요약

### 1.1 기존 기획의 강점

- 보호자의 불안이라는 감정 문제와 요양시설의 반복 업무 문제를 하나의 서비스로 연결했다.
- 보호자, 케어팀, 환자의 역할별 사용 맥락이 분리되어 있다.
- AI 일일 리포트는 단순 챗봇보다 서비스 가치가 선명하다.
- 요양보호사 앱에 실제 기록 업무와 법정 기록 분류가 반영되어 있다.

### 1.2 가장 큰 위험

- MVP가 너무 넓어 첫 사용자가 왜 반드시 써야 하는지 흐려진다.
- 보호자 유료 구독, 시설 구독, AI 모드 유료가 섞여 초기 구매자가 불명확하다.
- AI 케어가이드가 전면에 나오면서 정작 더 강한 가치인 "기록 자동 공유"가 약해진다.
- 환자 태블릿과 AI 말벗은 매력적이지만 운영, 윤리, 기기 관리 난도가 높다.
- 개인정보와 의료 정보 접근 기준이 제품 신뢰 수준까지 구체화되어 있지 않다.

### 1.3 새 제품 초점

> 하루안부는 요양시설의 일일 케어 기록을 보호자가 이해할 수 있는 안부 리포트로 자동 변환해주는 케어 커뮤니케이션 서비스다.

이 한 문장을 기준으로 기능 우선순위를 재정렬한다.

## 2. MVP 재정의

### 2.1 MVP 핵심 약속

> 매일 저녁, 보호자는 전화하지 않아도 가족의 하루 상태를 믿을 수 있게 확인한다.

### 2.2 MVP 포함 기능

| 우선순위 | 기능 | 대상 | 이유 |
|---|---|---|---|
| P0 | 케어 기록 입력 | 간호사, 요양보호사 | 서비스의 원천 데이터 |
| P0 | 보호자 오늘 상태 대시보드 | 보호자 | 매일 확인하는 핵심 화면 |
| P0 | AI 일일 안부 리포트 | 보호자 | 차별화 핵심, 전화 감소의 직접 수단 |
| P0 | 특이사항 및 SOS 알림 | 보호자, 케어팀 | 신뢰와 안전의 최소 조건 |
| P0 | 보호자 문의 및 시설 답변 | 보호자, 케어팀 | 전화 대체 채널 |
| P1 | 직원용 빠른 답변 템플릿 | 케어팀 | 반복 문의 처리 시간 감소 |
| P1 | 주간 안심 지수 | 보호자 | 리텐션용 요약 지표 |
| P1 | 인수인계 요약 | 간호사, 요양보호사 | 내부 업무 효율 증명 |

### 2.3 MVP 제외 또는 후순위

| 기능 | 결정 | 이유 |
|---|---|---|
| AI 케어가이드 5모드 | Phase 2 | 서비스 정체성이 챗봇으로 흐려질 위험 |
| 요양원 찾기 | Phase 3 | 입소 전 탐색 영역으로 핵심 MVP와 다름 |
| 비용 계산기 | Phase 3 | 보호자 획득용 콘텐츠로는 좋지만 도입 핵심은 아님 |
| 처방전, 진료기록 열람 | Phase 2 | 의료 정보 접근 권한 정리 후 진행 |
| 환자 태블릿 AI 말벗 | Phase 3 | 기기 운영, 인지 안전, 과의존 리스크 큼 |
| 낙상 감지, 건강 모니터링 | 장기 | 하드웨어, 인증, 책임 소재 난도 높음 |
| 데이터 분석 리포트 판매 | 장기 | 개인정보 활용 동의와 비식별 기준 필요 |

## 3. 사용자와 구매자 재정의

### 3.1 초기 고객 구조

| 구분 | 대상 | 서비스 내 역할 |
|---|---|---|
| 구매자 | 시설장, 간호팀장 | 도입 결정, 비용 지불 |
| 핵심 사용자 | 간호사, 요양보호사 | 기록 입력, 문의 응대 |
| 가치 수혜자 | 보호자 | 안부 확인, 문의 감소 |
| 보조 수혜자 | 환자 | 가족 연결감, 도움 요청 |

초기에는 보호자를 유료 고객으로 보지 않는다. 보호자는 만족도와 확산의 핵심이지만, 시설 데이터가 없으면 앱 가치가 거의 발생하지 않기 때문이다.

### 3.2 B2B 우선 수익 모델

| 상품 | 대상 | 가격 방향 | 포함 범위 |
|---|---|---|---|
| 시설 기본형 | 50명 이하 시설 | 월 99,000원 | 기록, 보호자 대시보드, 일일 리포트 |
| 시설 표준형 | 51~100명 시설 | 월 199,000원 | 기본형 + 문의 템플릿 + 통계 |
| 시설 확장형 | 100명 초과 시설 | 월 299,000원 이상 | 표준형 + 인수인계 요약 + 관리자 리포트 |
| 보호자 앱 | 보호자 | 무료 | 시설 구독에 포함 |
| AI 케어가이드 | 보호자 | 추후 유료 옵션 | 검증 후 도입 |

### 3.3 시설 도입 메시지

기존 메시지:

> 보호자, 의료진, 환자를 AI로 연결합니다.

개선 메시지:

> 보호자에게 매일 안부 리포트를 자동 발송해 반복 전화와 설명 시간을 줄입니다.

시설 입장에서 구매 이유는 "혁신적 AI"보다 "업무 시간 절감"이다.

## 4. 제품 구조 개선

### 4.1 역할별 제품 범위

| 트랙 | MVP 범위 | 후순위 |
|---|---|---|
| 보호자 앱 | 오늘 상태, 일일 리포트, 특이사항 알림, 문의 | AI 케어가이드, 비용 계산, 처방 상세 |
| 의료진 웹 | 환자 현황, 기록 확인, 문의 답변, SOS 대응 | 복잡한 메타포 대시보드, 고급 통계 |
| 요양보호사 앱 | 빠른 케어 기록, 특이사항, SOS | 급여 청구 PDF, 고급 근태 통계 |
| 환자 앱 | 가족 사진/음성, 도움 요청 | AI 말벗, 멀티 페이지 탐색 |

### 4.2 핵심 플로우

```
케어팀 기록 입력
  -> 환자별 오늘 상태 갱신
  -> 특이사항은 즉시 보호자 알림
  -> 저녁에 AI 안부 리포트 자동 생성
  -> 보호자는 리포트 확인
  -> 궁금한 점만 앱 문의
  -> 케어팀은 템플릿으로 비동기 답변
```

이 플로우가 MVP의 제품 뼈대다. 화면 수가 늘어나도 이 흐름을 방해하면 후순위로 둔다.

### 4.3 보호자 앱 첫 화면 개선

보호자 홈은 기능 모음이 아니라 "오늘 안심 확인"에 집중한다.

| 영역 | 내용 |
|---|---|
| 상단 | 오늘의 안부 상태: 안정 / 확인 필요 / 긴급 |
| 핵심 카드 | 식사, 투약, 수면/기분, 활동, 특이사항 |
| 리포트 | 오늘의 한 문장 요약 + 자세히 보기 |
| 문의 | "궁금한 점 남기기" 단일 진입 |
| 보조 | 최근 7일 추세 |

### 4.4 케어팀 입력 UX 개선

케어팀 앱은 예쁜 화면보다 빠른 입력이 우선이다.

| 원칙 | 적용 |
|---|---|
| 10초 입력 | 식사, 투약, 배변, 활동은 탭 중심 |
| 예외 중심 | 정상 기록은 짧게, 특이사항만 자세히 |
| 보호자 공유 미리보기 | 이 기록이 보호자에게 어떻게 보이는지 표시 |
| 반복 문의 줄이기 | 자주 묻는 질문에 자동 설명 붙이기 |
| 근무 중 방해 최소화 | 긴급, 확인 필요, 일반을 명확히 분리 |

## 5. AI 전략 수정

### 5.1 AI의 역할

AI는 제품의 주인공이 아니라 "번역기"다.

| 입력 | AI 처리 | 출력 |
|---|---|---|
| 케어 기록 | 보호자가 이해할 언어로 요약 | 일일 안부 리포트 |
| 특이사항 | 불안 자극을 줄이고 사실 중심 정리 | 보호자 알림 문구 |
| 반복 문의 | 시설 기준 답변 초안 생성 | 직원 검토 후 발송 |
| 인수인계 메모 | 핵심 변화와 주의사항 추출 | 교대 요약 |

### 5.2 AI 일일 리포트 원칙

- 진단하지 않는다.
- 처방 변경을 제안하지 않는다.
- 보호자 불안을 자극하는 표현을 피한다.
- 수치와 관찰 사실을 분리한다.
- 미확인 정보는 추정하지 않는다.
- 마지막 판단은 시설 담당자에게 문의하도록 안내한다.

### 5.3 리포트 구조

```
오늘의 한 문장
식사와 수분
투약
활동과 컨디션
특이사항
내일 확인하면 좋은 점
```

예시:

> 오늘은 식사와 투약이 모두 정상적으로 진행되었고, 오후에는 산책 활동에 참여하셨습니다. 저녁에 약간 피곤해하셔서 내일 오전 컨디션을 한 번 더 확인하겠습니다.

## 6. 개인정보와 의료 정보 기준

### 6.1 정보 분류

| 정보 | 예시 | 민감도 | 기본 공개 |
|---|---|---|---|
| 생활 기록 | 식사량, 활동, 수면, 기분 | 중간 | 보호자 공개 |
| 케어 기록 | 배변, 위생, 체위변경 | 높음 | 요약 공개 |
| 건강 기록 | 혈압, 체온, 혈당 | 높음 | 시설 정책에 따라 공개 |
| 의료 기록 | 처방, 진단, 진료 소견 | 매우 높음 | 의료진 승인 후 공개 |
| 응급 기록 | 낙상, 의식저하, 119 대응 | 매우 높음 | 보호자 즉시 알림 |
| 채팅, 사진 | 메시지, 이미지 | 높음 | 참여자만 |

### 6.2 역할별 접근 기준

| 역할 | 볼 수 있음 | 수정 가능 |
|---|---|---|
| 보호자 | 연결된 환자의 공개 기록, 리포트, 알림, 본인 채팅 | 문의, 가족 사진/메시지 |
| 요양보호사 | 담당 환자의 케어 기록, 본인 입력 기록 | 케어 기록, 특이사항 |
| 간호사 | 시설 환자 기록, SOS, 문의, 인수인계 | 케어 기록 검토, 의료 관련 메모 |
| 의사 | 담당 환자의 의료 기록, 타임라인 | 처방, 진료 소견 |
| 시설 관리자 | 시설 운영 통계, 권한 관리 | 사용자, 공개 범위, 시설 설정 |

### 6.3 필수 정책

- 보호자에게 공개되는 의료성 정보는 시설 정책과 담당자 승인 기준을 따른다.
- AI가 생성한 문구는 "AI 초안"으로 저장하고, 의료성 판단은 담당자가 최종 책임진다.
- 모든 조회, 수정, 공유 이벤트는 감사 로그로 저장한다.
- 사진과 채팅은 환자 및 보호자 동의 범위 안에서만 사용한다.
- 데이터 분석 리포트 판매는 MVP 범위에서 제외한다.

## 7. 경쟁 포지셔닝 수정

### 7.1 기존 경쟁 구도

기존 문서는 "입소 후 3자 실시간 소통 시장 공백"을 강조한다. 이 방향은 유지하되, 경쟁사를 기능 부족으로만 설명하면 약하다.

### 7.2 개선된 차별화 문장

> 기존 시설관리 솔루션은 행정과 청구를 위해 기록한다. 하루안부는 기록을 보호자의 안심 커뮤니케이션으로 바꾼다.

### 7.3 비교 축

| 축 | 기존 시설관리 SaaS | 하루안부 |
|---|---|---|
| 기록 목적 | 행정, 청구, 기관 관리 | 보호자 안심, 소통, 신뢰 |
| 보호자 역할 | 부가 열람자 | 핵심 수혜자 |
| AI 활용 | 기능 추가 가능성 | 기록을 보호자 언어로 변환 |
| 도입 명분 | 업무 전산화 | 전화 응대 감소와 신뢰 향상 |
| 초기 가치 | 내부 관리 효율 | 보호자 문의 감소와 만족도 |

## 9. 4주 개선 실행안

### Week 1: 기획 정리

- 통합기획서의 MVP 범위를 P0 중심으로 재정리한다.
- 보호자 유료 구독을 MVP에서 제외하고 시설 구독 중심으로 바꾼다.
- AI 케어가이드 5모드는 Phase 2로 내린다.
- 개인정보 접근표를 발표 자료와 설계 문서에 반영한다.

### Week 2: 화면 구조 정리

- 보호자 홈을 "오늘 안심 확인" 중심으로 재구성한다.
- 케어팀 입력 화면에 "보호자 공유 미리보기"를 추가한다.
- 환자 앱은 가족 사진/음성/도움 요청 중심으로 축소한다.
- 의료진 웹은 고급 메타포보다 문의 응대와 기록 검토 흐름을 우선한다.

### Week 3: 리포트 품질 개선

- AI 일일 리포트 프롬프트를 고정 구조로 만든다.
- 정상, 확인 필요, 긴급의 문구 톤을 분리한다.
- 의료성 표현 금지어와 대체 표현을 정의한다.
- 보호자 테스트용 리포트 샘플 5개를 만든다.

### Week 4: 검증 준비

- 시설 관계자 1명, 보호자 2명, 케어팀 1명에게 리포트 샘플을 보여준다.
- "이 리포트를 받으면 전화가 줄어드는가"를 직접 묻는다.
- 문의가 늘어나는 항목과 안심되는 항목을 분리한다.
- 발표 자료에는 전화 감소 ROI와 개인정보 기준을 함께 넣는다.

## 10. 발표용 핵심 문장

### 10.1 한 줄 소개

> 하루안부는 요양시설의 일일 케어 기록을 보호자용 안부 리포트로 자동 변환해, 반복 전화와 불안을 줄이는 케어 커뮤니케이션 서비스입니다.

### 10.2 문제

> 보호자는 매일 불안해서 전화하고, 시설은 같은 질문에 반복 응대하느라 돌봄 시간이 줄어듭니다.

### 10.3 해결

> 케어팀이 평소처럼 기록하면, 하루안부가 보호자가 이해할 수 있는 안부 리포트로 바꿔 매일 전달합니다.

### 10.4 차별화

> 기존 솔루션은 기록을 행정 자료로 남깁니다. 하루안부는 기록을 보호자의 안심으로 바꿉니다.

### 10.5 도입 명분

> 보호자 전화가 줄어들면 시설의 업무 시간이 줄고, 보호자는 더 자주 안심합니다.
