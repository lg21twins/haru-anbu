## 8단계 스텝퍼 (c02)

한 화면 한 항목, 한손 조작 기준. 각 단계는 `.st-step[data-step]` 로 스위칭:

1. 바이탈 — 혈압/체온/맥박/혈당 필드
2. 식사 — 식사량 슬라이더·형태 세그먼트·수분
3. 투약 — 약 체크 그리드·거부 메모
4. 위생 — 구강·세수·세발·목욕·손발 체크 그리드
5. 활동 — 보행·체위·프로그램 체크·총 활동시간
6. 배변 — 대변/소변/기저귀 (민감 · 별도 공유 설정 연동 예정)
7. 인지·정서 — 이모지 4단계·대화 요약·음성 입력
8. 특이사항 — 메모·사진·간호사 즉시 알림 토글
