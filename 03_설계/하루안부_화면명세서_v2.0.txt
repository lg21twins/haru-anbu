1. 화면 명세서 개요
────────────────────────────────────────────────
본 문서는 하루안부의 실제 구현 화면을 기록한 공식 명세서다. "진실의 원천"은
각 앱 폴더의 구현 HTML이며, 본 문서는 그 구조(화면·네비·기능)를 서술한다.
앱을 수정하지 않으며, 본 문서가 구현과 어긋나면 본 문서를 갱신한다.

전체 서피스 : 6개
  - 온보딩 (공통)        : 1화면  (v13)
  - 보호자 앱 (모바일)    : 16화면 (v11)
  - 요양보호사 앱 (모바일) : 5화면  (v11) + i18n(en·zh)
  - 환자 앱 (모바일/태블릿) : 9화면  (v12)
  - 의료진 앱 (모바일)     : 6화면  (v15)
  - 의료진 웹 (PC)        : 1 SPA / 8 메뉴 (v10)

사용자 분류 : 보호자 / 케어팀(의사·간호사·요양보호사) / 환자
