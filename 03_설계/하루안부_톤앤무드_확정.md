**v2.2 변경 요약 (2026-04-19)**

- **이모지 전면 금지 확정**: 모든 트랙(v9.5/v10/v11/v12/v13/v14) UI·문서에서 이모지(😊, 💊 등) 사용 금지. 아이콘은 `iconify-icon`(fluent:*)로 통일. `haru_anbu/CLAUDE.md` 규칙으로 등록.
- **의료진 웹 디자인 톤 확정**: 흰 카드 + 4px 좌측 악센트 + 빨강 단일(`#DC2626`). **원색 블록·그라디언트 카드·이모지·트리맵 은유 지양**. 탭별 시각 메타포 5종(투약=시간 타임라인, 기록=도넛+AI 큐, 인수인계=우선순위 트리맵, 환자=히트맵, 체크=도넛+타임라인)으로 단순 KPI 4-카드 반복 대체.
- **환자 태블릿 타이포 스케일 확정**: `data-role="patient"` 변형으로 본문 18px / 헤드라인 20px / 터치 56px / 액션 행 64px. "카드 한 개 = 한 화면, 스크롤 금지" 원칙.
- **요양보호사 디자인 제약**: 피크 08-10/18-20 amber 뱃지, 응급 1·2·3 스테퍼(녹색 사용 최소), 인수인계 5필수 체크(낙상·복약·통증·배회·가족통보) 컬러 시스템 확립.

## 무드

### 가야 할 느낌 (DO)

- 가족에게 보내는 **안심 편지** 같은 앱
- **카페에서** 편하게 열어보는 앱
- **둥근 모서리** (border-radius: 16px+), 부드러운 그림자
- **여백 넉넉** — "덜 보여주는 용기"
- **라인 일러스트** 포인트 — 간결하고 따뜻
- 부드러운 말투 — "~하셨습니다", "~해보세요"
- **카드 기반** 레이아웃 — 정보를 카드 단위로 분리

### 피해야 할 느낌 (DON'T)

- 차가운 **병원 차트** 느낌
- 의료 **키오스크** 느낌
- 날카로운 직선, 각진 UI
- 빽빽한 데이터 나열
- 스톡 사진 과다
- 딱딱한 말투 — "~하십시오", "~바랍니다"
- 불안을 자극하는 빨간색 과다 사용
