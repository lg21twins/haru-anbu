# 하루안부 · 디자인 시스템 쇼케이스 v14

**목적**: 5종 역할 앱을 한 화면에서 비교 (보호자·요양·온보딩·환자·간호사)
**입장 경로**: `index.html` 을 브라우저로 열기

---

## 담긴 것

| 칸 | 역할 | 플랫폼 | 파일 |
|---|---|---|---|
| ① | 온보딩 | 모바일 | `v13_온보딩/ob01-welcome.html` |
| ② | 보호자 | 모바일 | `v9_보호자앱/g-guardian-live.html` |
| ③ | 요양보호사 | 모바일 | `v11_요양보호사앱/c01-today.html` |
| ④ | 환자 | 태블릿 | `v12_환자앱/p01-today.html` |
| ⑤ | 간호사/의료진 | 데스크톱 웹 | `v10_의료진웹/m01-dashboard.html` |

각 칸은 iframe 프레임 안에서 실제 화면을 보여주므로 **토큰이 역할별로 다른 accent 컬러를 잘 뽑는지** 한 눈에 확인 가능.
