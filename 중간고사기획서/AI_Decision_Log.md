## PHASE 7 — 레이아웃 안정화 작업 (V2 픽스)

### 문제 진단

PDF 출력 대상 슬라이드에서 다음 3종류의 overflow 발생:

| 위치 | 원인 | 영향 슬라이드 |
|------|------|------------|
| lower zone 초과 | `height:343px` + `padding:40px` = 263px 콘텐츠 공간에 5개 line-metric(~380px) 배치 | Slide 26 (Impact) |
| 하단 항목 잘림 | `.lower`가 y=681~1024에서 끝나지만 콘텐츠 높이 초과 | Slides 08, 12, 16, 17 |
| 스크린 뷰 규격 불일치 | 1920px 고정 canvas가 viewport에 맞지 않아 가로 스크롤 발생 | 전체 |

### CSS 수치 조정 내역

**Lower Zone 확장:**
```
변경 전: .lower { top:681px; height:343px; padding:40px 120px; }
         → 가용 높이: 263px

변경 후: .lower { top:681px; height:399px; padding:36px 120px 56px; }
         → 가용 높이: 307px (+44px)
         → 56px bottom padding = bot-bar 겹침 방지
```

**컴포넌트별 간격 축소:**

| 컴포넌트 | 변경 전 | 변경 후 | 이유 |
|---------|--------|--------|------|
| `.line-metric` margin | 28px | 22px | 기본 metric 간격 정렬 |
| `.impact-lm .line-metric` margin | — (신규) | 13px | 5개 항목을 307px 안에 수용 |
| `.impact-lm .lm-val` font-size | 48px | 36px | 5행 × (36+13) = 245px < 307px |
| `.jtbd-item` padding | 32px 0 | 20px 0 | 3개 항목 수용 |
| `.diff-item` padding | 28px 0 | 16px 0 | 3개 항목 수용 |
| `.hmw-item` padding | 32px 0 | 14px 0 | 3개 항목 수용 |
| `.hmw-q` font-size | 22px | 19px | 줄바꿈 방지 |

**Viewport 스케일 (스크린 전용):**
```css
@media screen {
  .slide-outer { height: calc(var(--ss, 0.7) * 1080px); }
  .slide { transform: scale(var(--ss, 0.7)); }
}
/* --ss: JS로 clientWidth / 1920 계산, resize 이벤트 대응 */
```

**PDF @media print:**
```css
@page { size: 20in 11.25in; margin: 0; }
/* 1920×1080 = 20in×11.25in @96dpi */
.slide-outer { break-inside: avoid; page-break-inside: avoid; page-break-after: always; }
.slide { transform: none !important; }
```

**Box Model 통일:**
```css
*,*::before,*::after { box-sizing: border-box; } /* 전역 적용 확인 */
```
