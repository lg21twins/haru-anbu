## 2. 업데이트된 디자인 스펙

### 2-1. 레이아웃 골격

```
┌──────────────────────────────────────────────────────┐  y=0
│  TOP NAV BAR  (56px)                                 │
│  [로고]  01 OVERVIEW · 02 RESEARCH · ... · 07 IMPACT │
│  현재 섹션 = 진한색 + 하단 1.5px 밑줄                  │
├──────────────────────────────────────────────────────┤  y=56
│                                                      │
│  UPPER ZONE  (624px = 680–56)                        │
│  padding: top 72px left 120px                        │
│  → 핵심 메시지, 대형 수치, 메인 비주얼 1개             │
│                                                      │
├──────────────────────────────────────────────────────┤  y=680 (1px rule)
│  LOWER ZONE  (344px)                                 │
│  [키워드 340px] │ [바디 flex:1]                       │
│                ↑ 1px vertical rule                   │
├──────────────────────────────────────────────────────┤  y=1024
│  하단 바  36px  — 우측: 페이지번호                     │
└──────────────────────────────────────────────────────┘  y=1060 (여백 20px)
```

**핵심 변경사항 vs 이전 브리핑:**
| 항목 | 이전 | 변경 |
|------|------|------|
| 네비게이션 위치 | 하단 56px | **상단 56px** |
| 페이지 번호 위치 | 우상단 | **우측 하단** |
| 폰트 웨이트 | 400, 900만 | **300, 500, 700, 900** |
| 최소 폰트 크기 | 제한 없음 | **16px** |
