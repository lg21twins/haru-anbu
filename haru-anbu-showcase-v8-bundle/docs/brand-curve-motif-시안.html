안부 곡선 모티프 시스템

v1이 너무 흐릿했던 점을 고쳤습니다. 풀폭 squiggle 대신, 확실히 그려진 작은 마크 + 깔끔한 헤어라인 조합으로 “두 곡선이 만나 하나의 안부가 된다”를 또렷이 반복합니다.

※ 점검용 별도 파일. 라이브 쇼케이스는 미수정. 그라데이션·이모지·배경레일 없음, 단색 토큰만.

Motif 01

안부 곡선 디바이더

섹션 사이를 헤어라인으로 잇되, 가운데에 브랜드 마크를 또렷이 박습니다. 멀리서도 “하루안부 페이지”임이 읽힙니다.

규칙 준수 — 1px 헤어라인 + 중앙 마크. 색 면·보더 레일 아님.

옵션 A — 헤어라인 + 로고 심볼(블루)
실제 로고 심볼을 그대로 중앙에. 가장 직접적인 브랜드 신호.
옵션 B — 헤어라인 + 두 곡선 노트(추상 모티프)
두 곡선이 가운데서 맞물리는 작은 노트. 확실히 보이게 굵기·진폭을 키움.
옵션 C — 헤어라인 + 심볼(뉴트럴, 조용한 섹션용)
강조가 과하지 않게 회색 마크. 같은 시스템, 톤만 낮춤.

Motif 02

3자의 만남 — 연결선

보호자(블루)·케어팀(그린)·환자(오렌지) 세 가닥이 하나로 모여 → 하나의 안부 심볼이 됩니다. 이번엔 세 선이 한 점에서 부드럽게 합쳐진 뒤 아래로 한 줄기가 되어 로고로 내려갑니다.

규칙 준수 — 색은 ‘선’에만, 배경 색 면 없음.

세 시선이 하나의 안부로 — 하루안부가 연결하는 중심.

Motif 03

배경 라인아트 워터마크

로고 심볼을 크게, 5% 불투명도로 섹션 한가운데 깔아 “이 화면은 하루안부의 것”이라는 은은한 서명을 남깁니다. 텍스트 가독성 유지. Closing 섹션 배경에 적합.

규칙 준수 — 단색 5% 불투명도(그라데이션 아님), 콘텐츠 z-index 위.
