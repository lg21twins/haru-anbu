CONTEXT

역할이 4개일 때, PAIN ZONE을 어떻게 보여줄까?

현재 쇼케이스의 PAIN ZONE은 보호자 관점만 다루지만, 실제 사용자는 보호자 · 의료진 · 요양보호사 · 환자 4개 역할이 있어요. 같은 콘텐츠 셋으로 4가지 확장안을 비교합니다.

OPTION 1 · RECOMMENDED

역할 태그 인터리브 — 한 흐름에서 4개 역할을 교차

기존 sticky 스크롤 패턴을 유지하되, 각 카피 위에 역할 칩을 붙이고 보호자 → 요양보호사 → 의료진 → 환자 순서로 교차합니다. "모두가 동시에 힘들다"는 메시지가 한 흐름 안에서 자연스럽게 누적돼요.

  • 장점 흐름 안 끊김 · 분량 컨트롤 쉬움 (총 12카피, 기존 7카피 대비 +5)
  • 단점 역할별 메시지 깊이는 다소 얕음
AUTO PREVIEW
auto · 실제 적용 시 페이지 스크롤에 연동
OPTION 2

역할별 챕터 — 각 역할마다 독립된 PAIN 섹션 반복

현재 PAIN ZONE 패턴을 그대로 4번 반복합니다. 역할마다 자기 인트로 질문 + 카피 4~5개. 가장 명확하지만 스크롤 분량이 4배로 늘어나요.

  • 장점 역할별 메시지가 가장 깊고 명확
  • 단점 스크롤 매우 김 · 같은 패턴 반복 피로
AUTO PREVIEW · 챕터 전환
OPTION 3

역할 칩 전환형 — 사용자가 직접 역할을 선택

한 화면에 4개 역할 칩을 두고, 클릭하면 카피 셋이 교체됩니다. 가장 컴팩트하지만 사용자가 클릭하지 않으면 기본 역할 관점만 보고 지나칠 위험이 있어요.

  • 장점 매우 컴팩트 · 능동적 탐색 가능
  • 단점 클릭 안 하면 서사 누락 · 감정 누적이 약함
INTERACTIVE · 칩을 눌러보세요
OPTION 4

4-칼럼 스윔레인 — 4개 역할을 한 화면에 나란히

4개 칼럼으로 한 번에 비교. "모두가 힘들다"가 한눈에 보이지만, 현재의 cinematic한 한 줄 강조 톤이 사라지고 데이터 표 느낌이 됩니다.

  • 장점 한눈 비교 · 스크롤 절약
  • 단점 감정 톤 사라짐 · 모바일에서 좁아짐
