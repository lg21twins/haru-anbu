Active State Audit · 2026-05-25

Nav 활성 섹션 표시 — 시각적 변주 5종.

현재 active 상태는 연한 파란 칩(soft blue pill). 가장 안전하지만 한글 본문 톤과 비교해 다소 평범합니다. 같은 토큰(— brand #2C7AFC, ink, paper)으로 구현 가능한 5가지 대안을 한 화면에서 비교합니다.

Before · 현재

00.Soft blue pill

활성 항목에 연한 파란 배경 + 브랜드 텍스트. 안전하지만 6개 nav 중 1개만 칩이라서 시각 균형이 깨지고, hover/active 차이가 약합니다.

관찰된 문제

  • 균형감 — 1개만 chip이라 어색
  • 섹션 진행률 정보 없음
  • 한글 본문에 비해 가벼움

개선안 01 — Stripe · Vercel · Apple Docs

01.Underline slider.

활성 항목 하단에 2px 브랜드 라인. 스크롤 시 라인이 다음 항목으로 스르륵 슬라이드. 가장 절제된 클래식. 모든 항목이 균등한 무게라서 nav 전체 균형이 좋습니다.

강점

  • 균형감 최상 — chip 비대칭 해결
  • 슬라이드 애니메이션 자연스러움
  • 토큰 그대로 (border 2px / brand color)

개선안 02 — Linear · Notion · Arc

02.Top dot indicator.

활성 항목 위에 4px 브랜드 닷. 칩도 라인도 아닌 가장 가벼운 표식. 텍스트는 ink 색으로 굵어지고 dot만 brand로 — 깔끔하고 정보 밀도가 낮아 보입니다.

강점

  • 가장 미니멀 — 면적 거의 0
  • 한글 본문과 무게 균형
  • 다중 active 가능 (계층 nav 확장 시)

개선안 04 — Reading progress integrated

04.Section progress fill.

활성 항목의 pill 배경이 스크롤 진행률에 맞춰 채워짐. "이 섹션을 얼마나 봤는가"를 활성 칩 자체가 표현. 별도 progress bar 없이도 진행률 노출. 우측 % 라벨은 옵션.

강점

  • active + 진행률 동시 노출
  • 긴 페이지 쇼케이스에 최적
  • 별도 progress bar 불필요

개선안 05 — Apple chips · Vercel Dashboard

05.Inverted ink chip.

soft blue 대신 ink(검정) solid chip + white text. 가장 강한 대비. 활성 위치가 한눈에 들어오지만 brand 컬러가 빠져서 다른 곳(CTA · 본문 강조)에서 brand를 더 자유롭게 쓸 수 있음.

강점

  • 대비 최강 — 위치 인지 즉시
  • brand 컬러를 CTA에 양보
