현재 v8 헤더(좌측 로고 · 중앙 nav · 우측 CTA)는 균형 잡혀 있지만, 가운데 정렬된 uppercase nav가 시선을 분산시키고 보조 액션(데모 · 로그인)이 없습니다. Mobbin 상에서 가장 정제된 SaaS · 제품 쇼케이스 사이트의 헤더 패턴 5가지를 추출해 우리 토큰 그대로 재구성했습니다.

Before — 현재 v8

00.중앙 정렬 nav + 단일 CTA

좌측 로고 · 가운데 6개 uppercase nav · 우측 단일 CTA 구조. 모든 섹션 링크의 시각 가중치가 동일해서 우선순위(Problem → Direction → Features 흐름)가 묻히고, 11px uppercase 트래킹이 본문 한글과 톤이 어긋납니다.

관찰된 문제

  • 위계 부재 — 6개 nav 모두 같은 굵기 · 색
  • 이중 액션 부재 — 데모 · 로그인 진입로 없음
  • 한글 본문과 톤 불일치 — uppercase + 0.16em 트래킹
  • CTA 라벨 모호 — "앱 직접 체험"의 결과 예측 어려움

개선안 01 — Wrangle · Fibery 패턴

01.좌측 정렬 nav + 우측 듀얼 액션.

로고 옆에 nav를 붙여 좌→우 자연스러운 정보 흐름. 우측에는 로그인(텍스트) · 데모 보기(outline) · 앱 직접 체험(primary)의 3단 위계. 한글 본문 톤에 맞춰 uppercase를 제거하고 13px 자연 케이스로.

적용 변경점

  • nav 정렬: center → left (로고 옆)
  • 타이포: uppercase 11px → 자연 13px
  • 액션: 1개 → 3단 (텍스트·outline·primary)
  • active 표시: 파란 배경 칩 유지 (기존 토큰 재사용)

개선안 02 — Render 패턴

02.상단 announcement bar + 본 헤더.

헤더 위에 36px 짙은 announcement bar를 두어 시즌별 메시지(발표 영상 · 미디어 노출 · 채용)를 가장 먼저 전달. 본 헤더는 좌측 정렬로 정리해 정보 위계가 두 단계로 명확히 분리됩니다.

적용 변경점

  • 상단 announcement strip 36px 신설 (검정 bar)
  • 시즌별 메시지 슬롯: NEW · LIVE · 발표 라벨
  • 본 헤더는 V1 구조 유지 (좌측 정렬)
  • 스크롤 시 ann bar는 사라지고 헤더만 stick

개선안 03 — Coda · Figma 패턴

03.듀얼 CTA + 보조 nav hairline 분리.

섹션 nav와 액션 영역 사이를 얇은 hairline divider로 분리. CTA를 "발표 영상"(outline) + "앱 직접 체험"(filled) 듀얼로 구성해 제출용(심사위원)과 체험용(일반인) 동선을 동시에 노출합니다.

적용 변경점

  • 듀얼 CTA: outline + filled (Coda 방식)
  • hairline divider 1px × 18px로 영역 분리
  • 심사위원·일반인 동선 분기 가능
  • filled CTA는 --brand 대신 --ink(검정) — 본문 파란 액센트와 충돌 없음
REF Coda, Figma, v0, Time2book

개선안 04 — Portrait · mymind 패턴

04.플로팅 캡슐 nav (glass).

헤더 전체를 화면 위에 떠있는 capsule로 띄움. 양옆 여백 + drop shadow + 28px blur로 본문과 분리감 극대화. active 탭은 검정 칩으로 강조해 위치 인지를 명확히. 제품의 "섬세한 케어" 무드와 가장 잘 맞는 톤.

적용 변경점

  • 전체 헤더가 border-radius 999px capsule
  • backdrop-filter blur(20px) + saturate(180%)
  • box-shadow로 떠있는 감각 강조
  • active 상태: 검정 칩으로 강한 대비

개선안 05 — Linear · Apple 패턴

05.섹션 인식 적응형 헤더.

스크롤에 따라 헤더 중앙이 현재 섹션의 컨텍스트로 바뀝니다. ("03 · Direction · 케어팀 시점 ▾" 같은 형태) 페이지가 긴 우리 쇼케이스 구조와 가장 잘 맞으며, 하단 hairline progress가 진행률을 상시 노출합니다.

적용 변경점

  • 중앙 nav 대신 현재 섹션 컨텍스트 한 줄
  • 드롭다운 ▾ 클릭 시 전체 nav 펼침
  • 헤더 하단에 scroll progress 2px
  • 스크롤 위치 = 헤더 라벨 → 페이지가 "어디까지 왔는지" 즉시 인지

권장 — Recommended Combo

01(좌측 정렬) + 03(듀얼 CTA) + 05(progress bar만) 조합

01의 좌측 정렬 + 자연 case로 한글 본문 톤과 맞추고, 03의 듀얼 CTA(발표 영상 · 앱 체험)로 심사위원·일반인 동선을 분기하며, 05의 하단 progress bar 2px만 빌려와 페이지 진행률을 상시 노출.

04(플로팅 캡슐)는 매력적이지만 스크롤 시 본문과 겹치고 한국어 6 nav가 폭에 잘 안 들어옴. 02(announcement bar)는 행사 시즌(공모전 본선 · 발표)에만 한시적으로 ON 하는 옵션으로 보존.
