탭바 Hover 상태 — 개선안 5종

현재 hover는 옅은 회색 pill(paper bg)이라 active(브랜드 블루)와 위계가 모호함. 5개 방향을 톤·노이즈·브랜드 노출 강도별로 비교.

각 mockup의 “Direction” 항목에 HOVER PREVIEW 핀이 있는 것은 hover 상태를 강제로 켜둔 것 — 다른 아이템에 마우스 올리면 실제 hover도 동작합니다.
