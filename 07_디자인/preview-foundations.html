10. 다국어 (i18n)

요양보호사 역할은 외국인 사용자(중국 출신) 비율이 높음. Pretendard는 CJK Han 미커버 → Noto Sans SC 폴백.

한국어 (Pretendard)
오늘 어머님은 식사를 잘 드셨고, 오후엔 산책에 참여하셨습니다.
English (Pretendard Latin)
She had a good lunch today and joined the afternoon walk.
中文 简体 (Noto Sans SC)
奶奶今天午饭吃得很好,下午还参加了散步活动。
폰트 chain (tokens.css): 'Pretendard Variable', 'Pretendard', 'Noto Sans SC', 'Noto Sans', -apple-system, ... sans-serif
한·영은 Pretendard, 중국어 글자는 unicode 범위로 자동 Noto Sans SC 선택. 요양보호사앱 5개 HTML만 명시적으로 Noto Sans SC를 다운로드 (~150KB).

v3.2 · 매직넘버 명도 사다리 (§3.9, KRDS 차용)

KRDS의 명도 매직넘버(40/50/70/90)를 하루안부 그레이 스케일에 매핑. "본문 = 90 / 보조 = 70 / 보더 = 50 / 배경 = 40" 사다리 외 명도 사용 금지. 다크 모드에서도 동일 의미가 자동 반전.

--neutral-10 카드, 시트 표면
--neutral-40 페이지 배경
--neutral-50 디바이더, 보더
--neutral-70 보조 텍스트
--neutral-90 본문 텍스트 (4.5:1)
--neutral-strong 환자 고대비 (7:1)

v3.2 · 일러스트 시스템 (§15)

마스코트는 "사람과의 만남" 순간에만, 빈 상태·오류·중립 정보는 라인 일러스트. 라인 일러스트는 2px 단색 스트로크, round cap/join, currentColor 상속으로 다크 모드 자동 대응.

EMPTY STATE

"아직 기록이 없어요"

NETWORK ERROR

"잠시 연결이 불안정해요"

PERMISSION DENIED

"의료진만 볼 수 있어요"

마스코트 vs 라인 분리 — 마스코트는 환영·완료·축하 순간에만. 빈 상태에 마스코트가 나오면 친근함이 흐트러진다. 두 종류를 한 화면에 동시 사용 금지.

v3.2 · 액션 동사 매트릭스 (§1.5)

Fluent 2의 Done/Finish/Close/Dismiss 컨벤션을 한국어 톤에 맞춰 표준화. 컨텍스트별로 동사가 고정되어야 사용자가 학습 부담 없이 다음 화면을 예측할 수 있다.

닫기 계열 (4종)
  • 닫기 — 정보 보고 닫음 (작업 결과 없음)
  • 취소 — 진행 중 입력 버리기
  • 확인 — 정보를 봤다고 알림
  • 돌아가기 — 한 단계 위 화면
저장·완료 (5종)
  • 저장 — 다시 편집 가능
  • 완료 — 편집 모드 종료
  • 확정 — 되돌릴 수 없음
  • 전송 — 외부로 보냄
  • 제출 — 검증·승인 흐름
부정·위험 (3종)
  • 삭제 — 영구 삭제 (복구 명시)
  • 취소하기 — 예약·약속 취소
  • 나가기 — 채팅방 본인만 나감
시작·진행 (3종)
  • 시작 — 처음 진입
  • 계속 — 중단된 흐름 이어서
  • 다시 시도 — 실패한 동작 재시도
동사 + 명사 패턴 — 라벨은 의미 명확하게: "확인" → "메시지 보내기" / "등록" → "환자 등록" / "변경" → "비밀번호 변경" / "신청" → "본인 인증 제출".
