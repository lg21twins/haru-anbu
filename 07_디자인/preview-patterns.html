패턴

컴포넌트를 어떻게 조합해서 화면을 만드는지 — 홈 화면·AI 리포트·경보 위계·빈 상태·폼 검증·채팅·로딩 등 14개 패턴.

P1. 보호자 홈 — "오늘 안심 확인"

서비스개선안 v1.0 P0 핵심 화면. 위에서 아래로 1) 오늘 상태 → 2) 4축 요약 → 3) AI 리포트 → 4) 문의 → 5) 주간 추세.

핵심 규칙

  • 1순위 강조 1개 — 화면당 card-hero는 단 하나(오늘의 안부 상태). 나머지는 모두 card-default(흰 surface).
  • 4축 요약 — 식사·투약·수면·활동을 2×2 그리드로. 각 카드에 큰 숫자 + 상태 뱃지.
  • AI 리포트는 glass 예외 — 4곳 한정 중 하나(감성 영역). 액센트 보더로 "특별한 카드" 표시.
  • 일반 정보 카드에 glass·blur 사용 금지 — 텍스트 대비와 정보 밀도 우선.
  • 한 화면에 hero 카드 2개 이상 두지 않기 — 강조가 흐려진다.
Applies to
  • v11_보호자앱/g-guardian-live.html
  • v11_보호자앱/g-home-v31-pilot.html (★ system CSS 파일럿)

P2. AI 리포트 — 6 섹션 고정 구조

한 줄 요약 → 식사·수분 → 투약 → 활동·컨디션 → 특이사항 → 내일 확인할 점. 이 순서를 바꾸지 않는다.

AI 안부 리포트 · 2026.05.09 저녁
"오늘은 식사와 투약 모두 정상적으로 진행되었고, 오후에는 짧은 산책 활동에 참여하셨습니다."
식사와 수분 · 점심 2/3 드심, 저녁 정상. 물 섭취 6컵.
투약 · 아침·점심·저녁 3회 모두 정시 복용 완료.
활동과 컨디션 · 정원 산책 30분. 평소보다 짧은 시간이지만 컨디션은 좋아 보이심.
특이사항 · 저녁 식후 가벼운 어지러움 호소, 30분 안정 후 회복.
내일 확인할 점 · 오전 컨디션을 한 번 더 살펴볼 예정입니다.

P4. 경보 위계 — 4단계

위험도가 높을수록 더 침입적인 채널로. 한 화면에 단계 3은 1개만 — 동시 노출 시 긴급도 희석.

단계 0 · 정상
일반 케어 완료. 전용 알림 없이 카드 안에 success 뱃지만.
트리거: 일반 케어 완료 · 채널: 화면 안만
단계 1 · 정보
AI 리포트 발송, 메시지 도착, 새 댓글.
트리거: 일상 변화 · 채널: 푸시 + 인앱 토스트
단계 2 · 주의
미완료 케어, 늦은 투약, 컨디션 변화.
트리거: 일상 이탈 · 채널: 푸시 + 홈 card-alert--warning
단계 3 · 긴급
SOS · 의식 저하 · 119 호출.
트리거: 즉시 대응 필요 · 채널: 푸시 + 인앱 SOS Banner (닫기 없음) + SMS
Applies to (전 앱 공통)
  • v11_보호자앱/g06-alert.html
  • v15_의료진앱/d-sos.html
  • v11_요양보호사앱 — SOS FAB 전반

P5. 빈 상태 (Empty State)

"데이터 없음" 같은 시스템 메시지 금지. 사람이 사람에게 말하는 톤.

아직 오늘의 기록이 없어요
간호사가 첫 기록을 남기면 여기에 표시됩니다
검색 결과가 없어요
검색어를 다시 확인해보세요
잠시 연결이 불안정해요
다시 시도해주세요
이 정보는 의료진만 볼 수 있어요
보호자님께 공유 요청을 보낼 수 있습니다

긴급 알림이 이 번호로 전송됩니다
올바른 이메일 형식이 아니에요

P7. 로딩 스켈레톤

스피너보다 스켈레톤 우선. 실제 카드 형태로 자리를 미리 잡아 layout shift 방지. 짧은 작업(<300ms)은 아무것도 표시하지 않는다.

P8. 채팅 / 메시지

메시지 버블 좌하 꼬리(상대) / 우하 꼬리(나). AI 메시지는 좌측에 하루안부 심볼 + accent 보더.

안녕하세요, 어머님 컨디션이 어떠셨나요?
오늘은 평소보다 식사를 잘 하셨어요!
오늘 어머님은 점심 식사를 평소보다 많이 드셨고(2/3), 산책에 참여하셨어요. 컨디션이 좋아 보이세요.
감사합니다. 내일 면회 가능할까요?

P10. 적응형 레이아웃

모바일 앱은 PWA-first. 데스크톱에서 띄우면 phone 폭(~414px)으로 중앙 정렬.

너비 레이아웃 적용 앱
≤ 414px (Phone)단일 컬럼, 탭바 16px 인셋보호자 · 환자 · 요양 · 온보딩
415–767px (Phablet)단일 컬럼, 일부 카드 2컬럼모바일 앱
768–1023px (Tablet)중앙 정렬 + 양 거터, 사이드바 축소의료진 웹 + 모바일
1024–1279px (Small Desktop)사이드바 240px, 본문 가변 ≤ 1280px의료진 웹
≥ 1280px (Desktop)본문 1280px 고정, 여백 자동의료진 웹
