**버전: v2.0 | 2026.04.17** *(v9 보호자앱 기준으로 전면 갱신)*

> **실제 구현에서 사용할 토큰의 정의 파일은 `07_디자인/tokens/tokens.css` 하나입니다.**

## 8. 카드 컴포넌트 — v2.0 글라스모피즘

> v9부터 모든 카드는 **글라스모피즘 스타일**로 통일. 딱딱한 흰 카드가 아닌 배경 그라디언트와 융합되는 frosted glass 레이어.

### 기본 카드 (글라스 카드)
```
배경: rgba(255,255,255,.80)
backdrop-filter: blur(16px)
border: 1px solid rgba(255,255,255,.55)   ← 프로스티드 하이라이트 border
border-radius: 20px
box-shadow: 0 4px 20px rgba(0,0,0,.06)
padding: 18~20px
```

### 리스트 아이템 / 행
```
배경: rgba(255,255,255,.80)
backdrop-filter: blur(16px)
border: 1px solid rgba(255,255,255,.55)
border-radius: 14px
```

### 히어로 카드 / 강조 카드
```
배경: linear-gradient(135deg, --blue → --blue-d)
border-radius: 20~24px
shadow: 0 8px 28px rgba(44,122,252,.25)
color: 흰색
```

### 모달 / 바텀시트
```
배경: rgba(255,255,255,.97)
backdrop-filter: blur(40px)
border-radius: 28px 28px 0 0
box-shadow: 0 -4px 30px rgba(0,0,0,.10)
```

### border 3단계 규칙
| 용도 | border |
|------|--------|
| 일반 카드 | `1px solid rgba(255,255,255,.55)` |
| 글라스 UI (탭바, FAB, nav버튼) | `1px solid rgba(255,255,255,.45)` |
| 강조/특수 카드 (AI, SOS) | `1px solid rgba(44,122,252,.12)` 또는 역할 컬러 |

### shadow 토큰 (글라스모피즘용 추가)
| 토큰 | 값 | 사용처 |
|------|-----|--------|
| `--shadow-glass` | `0 4px 20px rgba(0,0,0,.08), inset 0 1px 0 rgba(255,255,255,.35)` | 탭바, FAB, nav버튼 |
| `--shadow-card` | `0 4px 16px rgba(0,0,0,.06)` | 일반 카드 |

## 18. 아이콘 시스템 — v2.0 확정

### 라이브러리: Fluent Icons Filled (단일 라이브러리, 컨텍스트별 크기)

**CDN**: `https://cdn.jsdelivr.net/npm/iconify-icon@2.3.0/dist/iconify-icon.min.js`

```html
<iconify-icon icon="fluent:{name}-24-filled"></iconify-icon>
<!-- CSS font-size로 시각 크기 조절. 크기 전용 variant(-16-/-20-/-28-filled)도 허용. -->
```

### 크기 규칙 (컨텍스트별)

| 컨텍스트 | 아이콘 variant | 렌더 크기 | 사용 예 |
|---|---|---|---|
| 탭바 (모바일) | `fluent:*-24-filled` | **24px** | 홈·가이드·소통·기록·마이 |
| 상단바 · 주요 버튼 | `fluent:*-24-filled` | **24px** | 알림 벨, 검색, FAB, 카드 헤더 |
| 사이드바 메뉴 (웹) | `fluent:*-24-filled` | **24px** | 대시보드, 환자 목록 메뉴 |
| 리스트 row 인라인 | `fluent:*-20-filled` 또는 `*-24-filled` | **20px** | 본문 중간 인라인 |
| 칩 · 배지 · 메타 라벨 | `fluent:*-16-filled` | **16px** | 상태 칩 (`SOS`, `투약 지연` 등), 작은 메타 |
| 브랜드/히어로 큰 심볼 | `fluent:*-28-filled` 이상 | 28~48px | SOS 배너 아이콘, 빈 상태 일러스트 |

> **토큰**: `--size-icon-sm: 20px`, `--size-icon-md: 24px`, `--size-icon-lg: 28px`, `--size-icon-xl: 32px` 사용. 16px는 칩 내부 전용 예외값.

### 스타일 원칙
| 항목 | 기준 |
|---|---|
| 스타일 | **Filled** (채움형) 단일 — Line/Outline 혼용 금지 |
| 라이브러리 | Microsoft Fluent Icons v2 (iconify `fluent:*-(16/20/24/28)-filled`) |
| 컬러 | `currentColor` 상속 (부모 `color` CSS 활용) |
| 커스텀 SVG | 로고 외 금지 (브랜드 심볼은 `07_디자인/logo/brand-system/` 사용) |

> **금지**: `ph:*` (Phosphor), `tabler:*`, `material-symbols:*` 혼용 배제. Fluent에 없는 아이콘만 예외적으로 허용하며, 팀 확인 필요.
