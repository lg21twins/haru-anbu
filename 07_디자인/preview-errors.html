P7 · ERROR STATES

에러 화면 4종

시스템 문제로 인한 화면. 동일 시각 구조(라인 일러스트 + 한 줄 카피 + 액션)지만 라이팅은 친근 ~요체. 시스템 메시지("Error 500", "Network failure")는 절대 금지 — 사람이 사람에게 말하는 톤.

1. 네트워크 오류 (offline / fetch fail)

와이파이·셀룰러 끊김. role="alert" + aria-live="assertive"로 스크린리더 즉시 안내.

잠시 연결이 불안정해요

와이파이나 모바일 데이터를 확인해 주세요

2. 서버 오류 (5xx)

시스템 일시 장애. 자동 재시도(지수 백오프 1s→2s→4s 최대 3회) + 사용자가 직접 재시도 둘 다 제공. 고객센터 진입점 함께.

지금은 잠깐 어려워요

잠시 후 다시 시도해 주세요. 문제가 계속되면 고객센터로 연락 주세요.

3. 권한 만료 / 미인증 (401 · 403)

세션 만료. 보안 이유를 친근하게 설명 + 재로그인 단일 액션. 자동 재시도 안 함.

다시 로그인이 필요해요

보안을 위해 일정 시간 후 자동 로그아웃됐어요

다시 로그인

4. 타임아웃 (timeout)

응답 지연. aria-live="polite"로 다른 안내 흐름 방해 안 함. "잠깐 멈췄어요" 톤.

응답이 늦어지고 있어요

잠깐 멈췄어요. 다시 시도하시거나 새로고침해 주세요.

절대 규칙

  • 라이팅: 시스템 메시지 금지 — "Error 500" · "Network failure" · "Timeout exceeded" 같은 영문/코드 노출 X. 시간·주체·해법을 한국어로 명시.
  • ARIA: 네트워크·서버는 aria-live="assertive", 권한·타임아웃은 polite.
  • 자동 재시도: 지수 백오프 1s → 2s → 4s, 최대 3회. 동시에 "다시 시도" 버튼도 항상 노출.
  • 환자앱: 본문 18px·터치 56px·카드 padding 24px 자동 상향 (토큰이 처리).
  • 요양보호사앱: 중국어 폴백 카피 동시 표시 ("연결을 확인해 주세요 / 请检查网络连接").
